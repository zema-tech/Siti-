# Siti-

Raccolta di siti e progetti web sviluppati e mantenuti da **zema-tech**.

## 📋 Descrizione

Questa repository ospita la raccolta di siti web, esercizi e progetti front-end. Ogni cartella contiene un progetto autonomo con i propri file statici (HTML, CSS, JS), pronto per essere aperto direttamente nel browser o pubblicato su GitHub Pages.

## 📁 Struttura

```
Siti-/
├── README.md
└── <nome-sito>/        # una cartella per ogni sito
    ├── index.html
    ├── style.css
    └── script.js
```

## 🚀 Come visualizzare i siti

1. Clona la repository:

   ```bash
   git clone https://github.com/zema-tech/Siti-.git
   ```

2. Apri il file `index.html` del sito che ti interessa nel browser.

In alternativa, puoi abilitare **GitHub Pages** dalle impostazioni della repository per pubblicare i siti online.
